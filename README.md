# NOIR — Netflix-inspired visual portfolio demo

A responsive streaming interface with nine photographic concept covers, a cinematic hero, searchable catalog, title details, sample playback, and a browser-local My List.

This is a static GitHub Pages demo. It has no backend, accounts, or credentials. My List is stored only in this browser and does not sync between devices. If browser storage is blocked, the list lasts only for the current visit. Clearing browser data removes the list.

All nine covers are original AI-generated concept images, not official film posters. Eight catalog titles are fictional. All playback uses the same 10-second excerpt from **Big Buck Bunny**, © 2008 Blender Foundation, licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). [Official licensing](https://peach.blender.org/about/). The bundled excerpt comes from [W3Schools](https://www.w3schools.com/html/mov_bbb.mp4).

NOIR is an educational portfolio project and is not affiliated with Netflix. The full local application separately implements a Node.js backend, SQLite accounts, and per-user watchlists.

To preview locally, serve this directory with a static web server. Enable GitHub Pages from the repository branch root to publish. All asset paths are relative and support a project subdirectory.
